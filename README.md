# David Margot — Engineering Leadership

A static portfolio for SRE and platform engineering leadership, built with semantic HTML, CSS, and a small progressive-enhancement script. No build step or runtime dependencies.

## Local preview

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Open [http://localhost:4173](http://localhost:4173). GitHub Pages serves the same files at [dm-resume.github.io/resume](https://dm-resume.github.io/resume/).

## Content

- `index.html`: introduction, selected projects, career history, expertise, education, and contact links.
- `styles.css`: responsive editorial layout, reduced-motion support, and print styles.
- `main.js`: mobile navigation and copyright year. All primary content remains available without JavaScript.
- `assets/fonts/`: self-hosted DM Sans and Instrument Serif; license notices included.

Content was updated from David Margot’s 2026 resume in November 2026. Dates, titles, and results are attributed to their respective employers. LinkedIn is the only contact destination; no resume PDF or email address is published. Team scope is described without headcount or team-count figures; retain measurable reliability and performance outcomes.

## Before publishing

Check desktop and mobile layouts, keyboard navigation, expandable project details, LinkedIn links. Relative asset paths support the GitHub Pages `/resume/` subpath.
